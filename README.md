Yahaha is Seven's personal website: a folded-paper map of apps, browser tools, open-source projects, reading and links. Pick a city, fly in, or take a tour. The landscape changes with the domain you visit, and its light follows your local time.

The map is available in Simplified Chinese, Traditional Chinese, Japanese and English.

## Find your way around

- **Apps and projects** — discover Seven's apps and open-source work.
- **Browser tools** — solve a puzzle, find an emoji, make a face, or try something new.
- **Reading and links** — visit the Heart Sutra and other places around the web.

## Tools to try

| Tool                                         | What you can do                                                          |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| [24 Points](https://yahaha.net/24points)     | Find ways to make 24 from four numbers.                                  |
| [Tarot](https://yahaha.net/tarot)            | Explore the 22 Major Arcana and their upright and reversed meanings.     |
| [Emoji](https://yahaha.net/emoji)            | Search and copy emoji in Chinese or English.                             |
| [Emoticon Kit](https://yahaha.net/emoticon)  | Make and copy a kaomoji.                                                 |
| [ASCII Art](https://yahaha.net/ascii-art)    | Turn text into ASCII art.                                                |
| [Morse Code](https://yahaha.net/morse)       | Translate between text and Morse code.                                   |
| [Face Kit](https://yahaha.net/face)          | Turn a name into an SVG avatar.                                          |
| [Lock Kit](https://yahaha.net/lock)          | Explore single- and double-row key bitting codes.                        |
| [Heart Sutra](https://yahaha.net/heart/hans) | Read it in Simplified Chinese, Traditional Chinese, English or Sanskrit. |

The tools run in your browser. Pick one and give it a try.
