## 已补全

- 24 点求解器改用 BigInt 精确分数，覆盖全部二叉表达式结构，去除交换运算重复项；表单校验 1–13 的整数，输入变化后清除旧结果。无障碍状态区域仅播报结果数量或无解提示，完整解法列表放在其外。
- 摩斯码支持编码与解码，统一字母及单词分隔符；未知输入保留 `?`，显示和复制使用同一个结果。
- 摩斯码和颜文字使用键盘可操作的复制按钮，提供成功及失败反馈，并忽略过期的异步复制结果。
- 补齐输入标签、标题层级、首页返回入口和文字对比度；主题存储异常可降级，支持跨标签同步。
- 补齐语言标记、页面描述、canonical、Open Graph、Twitter、sitemap、robots 和站内 manifest 快捷入口；静态吉祥物取消 hydration。
- 配置 ESLint、类型检查、回归测试、构建产物校验及 GitHub Actions；更新文档和有已知漏洞的间接依赖。

## 可重复检查

```sh
pnpm install --frozen-lockfile
pnpm verify
pnpm audit
```

`pnpm verify` 包含 lint → Astro/TypeScript 检查 → Node/Python 测试 → 生产构建 → 静态产物检查。此次全部通过；20 项 Node 测试及 3 项 Python 测试通过，lint 和类型检查没有错误或警告，依赖审计未发现已发布漏洞。

24 点测试与独立的五种括号结构、数字排列及运算符穷举算法比较了全部 1,820 组无序输入的可解性，并用独立解析器检查每条返回式子的精确结果和数字使用次数。另覆盖 `3,3,8,8`、`1,5,5,5`、无解、重复数字及非法输入。

摩斯码测试覆盖字母、数字、标点、单词分隔、Unicode 未知字符、排版用点划符、未知编码和全部支持字符的往返转换。

静态产物检查覆盖 10 个页面、语言及分享元数据、站内链接和资源、sitemap 完整性、manifest 快捷入口和吉祥物不 hydration。
