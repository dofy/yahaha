# 验证记录

日期：2026-09-28。范围：本地源码及生产静态构建；Node 22.23.3、pnpm 10.22.0。

## 已补全

- 24 点求解器改用 BigInt 精确分数，覆盖全部二叉表达式结构，去除交换运算重复项；表单校验 1–13 的整数，输入变化后清除旧结果。无障碍状态区域仅播报结果数量或无解提示，完整解法列表放在其外。
- 摩斯码支持编码与解码，统一字母及单词分隔符；未知输入保留 `?`，显示和复制使用同一个结果。
- 摩斯码和颜文字使用键盘可操作的复制按钮，提供成功及失败反馈，并忽略过期的异步复制结果。
- 补齐输入标签、标题层级、首页返回入口和文字对比度；主题存储异常可降级，支持跨标签同步。
- 补齐语言标记、页面描述、canonical、Open Graph、Twitter、sitemap、robots 和站内 manifest 快捷入口；静态吉祥物取消 hydration。
- 配置 ESLint、类型检查、回归测试、构建产物校验及 GitHub Actions；更新文档和有已知漏洞的间接依赖。

## 可重复检查

```sh
pnpm install --frozen-lockfile
pnpm verify
pnpm audit
```

`pnpm verify` 包含 lint → Astro/TypeScript 检查 → Node/Python 测试 → 生产构建 → 静态产物检查。此次全部通过；20 项 Node 测试及 3 项 Python 测试通过，lint 和类型检查没有错误或警告，依赖审计未发现已发布漏洞。

24 点测试与独立的五种括号结构、数字排列及运算符穷举算法比较了全部 1,820 组无序输入的可解性，并用独立解析器检查每条返回式子的精确结果和数字使用次数。另覆盖 `3,3,8,8`、`1,5,5,5`、无解、重复数字及非法输入。

摩斯码测试覆盖字母、数字、标点、单词分隔、Unicode 未知字符、排版用点划符、未知编码和全部支持字符的往返转换。

静态产物检查覆盖 10 个页面、语言及分享元数据、站内链接和资源、sitemap 完整性、manifest 快捷入口和吉祥物不 hydration。

## Emoji 词库升级

- 接入 Emoji 17.0 全部 3,944 个 fully-qualified 序列，CLDR 48.2 简繁中文及英文基础/派生名称与关键词；每个 Emoji 的三种语言名称完整，保留原输入法别名。合并后有 42,796 个不同搜索词。
- 解析本机 CoreEmoji UTF-16 trie，直接关联内部编号与现代简繁词库，两套各 1,878 条文档全部匹配；保存已映射快照、原始权重、系统版本及 SHA-256，生成流程不靠翻译名称猜测。[数据来源及更新步骤](emoji-data.md)。
- 增加完整名称、精确同义词、前缀、子串与多词匹配排序，实际 Emoji 去重；支持直接 Emoji、简繁关键词、英文大小写和旧 keycap 形式。
- 新增 8 项 Node 测试和 3 项 Python 二进制样本测试，覆盖全部 3,944 个序列直接搜索、Apple 新词、排序、去重、历史别名与损坏格式拒绝；重复生成三个数据文件逐字节一致。
- 浏览器确认“收到”→🫡、“粉心”→🩷、“浴火重生”→🐦‍🔥、“眼袋”→🫩、“指紋”→🫆、繁体熊猫及旧 keycap 搜索；分页从 60 增至 120 个候选；键盘操作有 2px 可见焦点，复制参数是实际 Emoji，成功/失败反馈通过故障注入验证。
- 通过真实生产静态文件的临时故障服务器验证首次词库请求 503、重试时延迟 1.2 秒及恢复后的查询保留；静态 JSON 带内容哈希，构建校验确认文件及 Unicode 许可均随产物发布。
- 输入组合事件模拟期间保留此前候选，结束后“收到”候选更新，输入焦点与光标位置保留；这不是实际中文输入法或真机测试。
- Emoji 页面实测 320、390、1280 像素宽度及明暗主题均无横向溢出；等待主题动画完成后，明暗主题 axe WCAG 2 A/AA、2.1 AA 明确违规为 0。此轮完整本地验证通过，依赖审计 0 已知漏洞。
